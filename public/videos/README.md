# Video Demonstration Assets

Place your project demo video file here:
- Recommended filename: `hero-demo.mp4` (or `project-demo.mp4`)
- Path: `public/videos/hero-demo.mp4`

Supported formats: MP4 (H.264 / AAC), WebM.
The HeroVideo component in `src/components/ui/HeroVideo.tsx` automatically plays this video with autoplay, mute/unmute controls, and looping.
If no video file is present, a high-tech simulated acoustic waveform visualizer automatically renders as a seamless fallback.
